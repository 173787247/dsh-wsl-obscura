# Contributing

Issues and PRs are welcome for `dsh-wsl-obscura`.

1. Keep tools small and WSL/Windows-boundary safe (http(s) only; private network opt-in).
2. Do not turn this into a second `win_open_url` — that stays in `dsh-wsl-browser`.
3. Run `npm test` when tests exist.
4. Update `README.md` and `README.zh.md` together when behavior changes.
